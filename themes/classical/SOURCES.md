# Classical theme sources

The coastal statue wallpaper and transparent Eucleia header were generated
with OpenAI ImageGen from a user-supplied concept. The wallpaper was edited to
remove interface overlays and darken the left side for live text. The header
contains the laurel, wordmark and tagline. The cursor, divider, Windows icon
and boot/navigation symbols were created for this project.

## Fonts

Cinzel is by Natanael Gama. EB Garamond is by Georg Duffner and Octavio Pardo.
The source font binaries are unchanged. The compiler creates static instances
for the pack. Both families use the SIL Open Font Licence; retain their
`fonts/cinzel/OFL.txt` and `fonts/ebgaramond/OFL.txt` when redistributing.
